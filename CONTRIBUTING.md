# Contributing to Denominated

Thanks for helping make purchasing-power concepts easier to understand.

## Report a bug or share feedback

You do not need repository write access to open a GitHub issue. Use the public
[new issue page](https://github.com/swright7001/denominated-mvp/issues/new/choose)
and select **Bug report** or **Product feedback**.

Before attaching a screenshot or recording, remove email addresses, names,
verification codes, payment details, API keys, and other private information.
Security vulnerabilities belong in a
[private security advisory](https://github.com/swright7001/denominated-mvp/security/advisories/new),
not a public issue.

## Submit a code change

1. Fork the repository into your own GitHub account.
2. Create a focused branch from `main`.
3. Make the smallest change that resolves the issue.
4. Run `npm test`, `npm run lint`, and `npm run build`.
5. Push the branch to your fork and open a pull request against this repository.

External contributors do not need direct write access. The pull-request template
asks for a Linear issue when one exists; write `Not available` when the change
came from a public GitHub issue.

Keep the calculator educational and consumer-friendly. Avoid trading prompts,
price hype, financial-advice claims, unrelated refactors, and provider secrets.
