# Scenario Image Inventory

Denominated uses the provided logo and UI references as the approved visual source for the MVP image set. Scenario images should stay dark, premium, consumer-finance oriented, and aligned with the copper/off-white brand system.

## Image Policy

- Primary images render on Examples cards and scenario detail pages.
- Alternate images are curated editorial replacements only for now.
- Alternates are recorded in scenario data but are not rendered in the app yet, which avoids adding page weight until a real selector, A/B test, or replacement decision exists.
- Missing imagery falls back to the existing icon treatment.
